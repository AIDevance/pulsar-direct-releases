# Pulsar Direct

Direct P2P messenger от AIDevance для **Windows и Android**. Ваша информация доступна только вам и собеседнику. Сквозное шифрование всей переписки и звонков. Ничего не хранится на серверах.

**[Скачать последнюю версию](https://github.com/AIDevance/pulsar-direct-releases/releases/latest)** · [Все выпуски](https://github.com/AIDevance/pulsar-direct-releases/releases)

## Что скачать

| Система | Файл в выпуске |
| --- | --- |
| Windows 10/11, x64 | `Pulsar-Direct-windows.exe` |
| Android 8 и новее | `Pulsar-Direct-arm64-v8a.apk` |

Прямые ссылки на последнюю версию:

- Windows: https://github.com/AIDevance/pulsar-direct-releases/releases/latest/download/Pulsar-Direct-windows.exe
- Android: https://github.com/AIDevance/pulsar-direct-releases/releases/latest/download/Pulsar-Direct-arm64-v8a.apk

## Установка

**Windows.** Запустите `Pulsar-Direct-windows.exe`. Обновления программа получает сама.

**Android.** Откройте `Pulsar-Direct-arm64-v8a.apk` на телефоне и разрешите установку из этого источника, если телефон спросит.

## Проверка файлов

В каждом выпуске лежит `latest.json` с номером версии и SHA-256 каждого файла.
